# Roteiro

Cada marco termina com uma versão utilizável.

| Marco | Conteúdo | Estado |
|---|---|---|
| M0 | Fundação: Docker, login, projetos, membros, convites, CI | pronto |
| M1 | Importação (RIS, BibTeX, PubMed, CSV), registro de buscas, enriquecimento de metadados, deduplicação | pronto |
| M2 | Triagem cega pelo teclado, destaque de palavras-chave, etiquetas, filtros, conflitos, concordância, PRISMA 2020, exportação | pronto |
| M3 | IA plugável (local ou remota), triagem assistida, calibração, controle de custo, aprendizado ativo e critério de parada | em andamento (provedores, triagem por IA e calibração prontos) |
| M4 | Texto completo: PDFs, busca de acesso aberto, visualizador, agrupamento de relatórios por estudo | planejado |
| M5 | Extração de dados e risco de viés, com citação literal verificada no PDF | planejado |
| M6 | Síntese, snowballing, buscas por API, relatórios, conversa com o corpus, API pública e servidor MCP | planejado |
